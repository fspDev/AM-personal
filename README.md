# Entreno

App de entrenamiento para el celular: armás tu rutina y la app te lleva bloque por bloque (series con peso y descanso, bici por tiempo, circuitos), con ventana flotante, avisos, progreso y récords.

**Demo:** https://fspdev.github.io/ENTRENO/

Versión de muestra de un solo usuario: todo queda guardado en el teléfono, sin cuentas ni servidor. Se instala como app desde Chrome (*Agregar a la pantalla de inicio*) y funciona sin conexión.

```bash
npm install
npm run dev
npm test
```
